# MGDP GO2 AMP V1 地形修订设计

## 1. 状态与范围

本文记录云服务器 Viewer 暴露问题后确认的 V1 地形修订。它只替代
`2026-10-12-mgdp-go2-amp-final-design.md` 中的正式地形集合、地形几何、
相应 command/reward 条件和地形验收矩阵。AMP、WM、PPO、观测边界、随机化
范围、paired checkpoint、manifest 和正式训练流程继续沿用原冻结设计。

旧 5000-iteration AMP/noAMP 运行保留为旧地形实现的诊断证据，不得作为修订后
地形的正式结果继续续训，也不得被新运行覆盖。

## 2. 修订依据

云端地形总览确认当前实现存在以下问题：

- 所有地形完成生成后，中心 `2 m x 2 m` 区域被统一写为高度 0；
- 坡道和楼梯原本与主体连续的顶部平台因此被挖成随难度加深的中心坑；
- gap 形成围绕中心出生岛的护城河，而不是沿前进方向的跨越地形；
- narrow passage 和随机离散障碍产生零碎、难以解释的墙段；
- 十类地形存在能力重叠，20 个等级超出 V1 所需粒度。

参考原始 WMP 和 WMP_go1 后，本修订采用 WMP_go1 定向地形的纵向组织思想，
但不复制其悬崖、跑酷、钻越或极端参数。原始 WMP 的高度连续平台原则保留。

## 3. 正式地形集合

| 地形 | 比例 | 主要能力 |
| --- | ---: | --- |
| `flat` | 15% | 平地速度跟踪与转向基线 |
| `rough_ground` | 15% | 连续低幅粗糙地面适应 |
| `slope_course` | 20% | 上坡、坡顶转换和下坡 |
| `stairs_course` | 20% | 上楼梯、顶部转换和下楼梯 |
| `low_obstacle_course` | 15% | 普通步态跨越低障碍 |
| `gap_course` | 10% | 普通步态跨越有限宽度沟槽 |
| `narrow_passage` | 5% | 航向稳定、深度感知和身体避碰 |

V1 不再包含独立的 `pit`、随机重叠矩形、continuous gap、beam/bridge、
stepping stones、cliff、tilt、stool、crawl 或高障碍攀爬地形。

## 4. 全局几何规则

- 单元保持 `8 m x 8 m`，机器人沿局部 `+X` 穿越。
- `num_rows=10`，level 为 `0..9`，统一难度 `d=level/9`。
- 结构化地形从单元前部的平坦出生区开始，不再从中心出生。
- 出生区、主体、缓冲区和出口由各地形生成器直接构造；禁止在生成后统一将
  中心区域清零。
- 顶部或中间平台的高度必须继承相邻地形表面，不能固定为世界高度 0。
- 几何在同一 level 和 seed 下可复现，难度只改变本节明确列出的参数。
- 地形不得越过自己的 `8 m x 8 m` 单元边界。

结构化地形的名义出生中心位于局部 `x=0.65 m`、横向中心线，X 随机范围
收紧为约 `±0.10 m`。flat 继续允许小范围 XY 随机；rough_ground 在其前置
平面内出生。

## 5. 各地形参数

### 5.1 flat

完全平整，所有 level 几何相同，作为控制基线。

### 5.2 rough_ground

纵向为 `1.3 m` 平坦出生段、`5.4 m` 连续粗糙区和 `1.3 m` 平坦出口段。
粗糙区两端平滑过渡到高度 0，不产生垂直断层。

```text
maximum_height_amplitude = 0.005 m + 0.045 m * d
```

高度场必须连续、经过空间平滑并保持近似零均值；不生成矩形、尖柱或坑洞。

### 5.3 slope_course

固定纵向骨架：

```text
1.3 m 前置平台
+ 2.1 m 上坡
+ 1.2 m 顶部平台
+ 2.1 m 下坡
+ 1.3 m 出口平台
= 8.0 m
```

```text
slope_ratio = 0.05 + 0.25 * d
top_height = slope_ratio * 2.1 m
```

坡比范围为 `0.05..0.30`，约 `2.9..16.7 deg`。顶部平台严格位于坡顶高度，
下降段回到基础高度。V1 坡面保持平滑，粗糙度由 rough_ground 单独覆盖。

### 5.4 stairs_course

与 slope_course 使用相同纵向骨架。上、下楼梯各 7 级，踏面深度固定为
`0.30 m`，顶部平台长度为 `1.20 m`。

```text
step_height = 0.05 m + 0.09 m * d
```

单级高度范围为 `0.05..0.14 m`。顶部平台高度等于 7 级台阶累计高度；台阶
数量、踏面深度和平台长度不随 level 改变。

### 5.5 low_obstacle_course

三个横向低障碍的中心位于局部 `x=2.0, 4.0, 6.0 m`。每个障碍沿 X 方向
宽 `0.30 m`，横跨行进区域，互不重叠。

```text
obstacle_height = 0.04 m + 0.12 m * d
```

高度范围为 `0.04..0.16 m`。不生成随机矩形、迷宫或高墙攀爬。

### 5.6 gap_course

两条横向沟槽分别位于局部 `x` 约 `2.6 m` 和 `5.4 m`，中间保留约
`2.8 m` 的基础高度恢复区。沟槽横跨行进区域，深度固定为 `1.0 m`。

```text
gap_width = 0.10 m + 0.25 m * d
```

沟宽范围为 `0.10..0.35 m`。不加入连续小平台、跳石或独木桥。

### 5.7 narrow_passage

纵向为 `1.3 m` 开放出生段、`0.7 m` 渐进收窄入口、`4.0 m` 等宽通道、
`0.7 m` 渐进放宽出口和 `1.3 m` 开放出口段。墙高固定为 `0.35 m`。

```text
passage_width = 1.50 m - 0.50 m * d
```

净宽范围为 `1.50..1.00 m`。墙体连续，不加入急转弯、岔路、顶棚或下蹲任务。

## 6. Command 与课程

不引入 WMP_go1 的五套动态速度课程，只保留两组固定规则：

- `flat`、`rough_ground`：`vx=0..0.8 m/s`，`yaw=-1..1 rad/s`，允许 idle、
  原地转向和前进转向；
- 其余五类结构化地形：有效 `vx` 位于 `0.2..0.8 m/s`，固定 `yaw=0`，
  不采样 idle。

所有环境从 level 0 开始。现有课程规则继续使用：前向位移达到 `4 m` 升一级，
在达到 `4 m` 前提前失败降一级，level 9 成功后按现有规则回收到随机较低等级。
不增加按地形独立的速度课程或升级公式。

## 7. 奖励适配

- task、regularization、AMP reward 及权重保持不变；
- `feet_edge` 只对 gap_course 生效；20 级时的 `level>3` 按归一化难度换算为
  10 级时的 `level>=2`；
- 结构化地形航向偏离条件更新到新的五类 ID；
- narrow_passage 不增加专用碰墙奖励，沿用碰撞惩罚和 base-contact 终止；
- `lin_vel_z` 保持 `-1.0`，不恢复旧 MGDP 的数字地形 ID 隐式缩放。

配对评估为每个 case 记录平均 `base_lin_vel_z^2`。若修订后短跑和 Viewer 同时
证明 stairs、low obstacle 或 gap 的必要垂向运动受到压制，再基于实测提出具名
地形缩放；本修订不预先改变权重。

## 8. Viewer 与验收

- 地形总览显示 7 类地形的代表等级 `0/3/6/9`，共 28 个 tile；
- 行为 Viewer 继续使用单 case、固定 terrain/level/command/seed；
- 地形总览打印行列、地形名称、level 和训练比例，不要求场景文字标牌；
- 默认相机居中覆盖网格，不能持续强制覆盖用户鼠标调整；
- narrow passage level 9 只需总览确认入口正确，再运行一次普通单 case Viewer，
  不建立专项评分器；
- 自动测试验证单元边界、出生区、关键段长度、平台高度连续性、难度单调性和
  固定 seed 可复现性。

AMP/noAMP 配对评估必须使用相同的新地形 case、seed、command 和 episode 条件。
旧地形 checkpoint 不能参与修订后正式比较。

## 9. 运行与文档边界

- 修订实现必须使用新的运行目录命名空间，避免覆盖现有 1000/2000/5000
  iteration 产物；具体名称在实施计划中确定；
- 旧运行保留并标注为“修订前地形实现”；
- README 在实现完成后更新命令和正式地形说明；
- `MGDP_GO2_AMP_V1_INITIAL_BASELINE.md` 只在云服务器验证通过并经用户同意后
  更新，不把本地设计决定写成已验证事实。
